Questions fréquentes

L'application fournit-elle des chaînes ?
Non. Teluna iPTV est un lecteur : vous ajoutez votre propre abonnement Xtream Codes ou playlist M3U. Une petite sélection de chaînes d'information diffusées gratuitement par leurs éditeurs permet d'essayer l'application.

Comment ajouter mon abonnement ?
Réglages → Playlists → Ajouter une playlist, puis saisissez l'adresse M3U ou les identifiants Xtream Codes fournis par votre fournisseur.

Une chaîne se bloque ou ne démarre pas.
L'application relance automatiquement les flux qui coupent et augmente sa mémoire tampon si besoin. Si le problème persiste, vérifiez que votre abonnement n'est pas utilisé sur un autre appareil (beaucoup n'autorisent qu'une connexion), essayez une connexion filaire sur Apple TV, ou réglez Réglages → Lecture → Mémoire tampon sur « Élevé ».

J'ai oublié mon code parental.
Réglages → Données → Réinitialiser l'application (vos playlists devront être ajoutées à nouveau).
